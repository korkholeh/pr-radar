{% translate "How a pull request gets into the AI cohort" %}

{% blocktranslate trimmed %} Every AI metric — AI PR share, the AI and non-AI comparisons, the AI cohort filter — counts the pull requests in the AI cohort. Each pull request gets one AI status, checked in this order; the first that applies wins. {% endblocktranslate %}

  1. {% translate "AI explicit" %} — {% blocktranslate trimmed %} a high-confidence detection rule matched something an AI tool wrote itself: a co-author trailer or footer in a commit, a footer or marker in the description, a bot as the author, the tool's own file in the diff. {% endblocktranslate %} {% if rules.high_confidence_tools %} {% blocktranslate trimmed with tools=rules.high_confidence_tools|join:", " %} Tools the active rules recognise: {{ tools }}. {% endblocktranslate %} {% endif %} {% translate "In the AI cohort." %}
  2. {% translate "AI disclosed" %} — {% blocktranslate trimmed %} the author ticked "Partial" or "Substantial" in the "AI assistance" section of the pull request template. {% endblocktranslate %} {% translate "In the AI cohort." %}
  3. {% translate "AI suspected" %} — {% blocktranslate trimmed count count=rules.min_structural_kinds %} only medium- or low-confidence rules matched (a branch prefix, an AI reviewer account, the wording of the description), or at least {{ count }} kind of structural signal did (a large change within two hours, a burst of commits, many new files). {% plural %} only medium- or low-confidence rules matched (a branch prefix, an AI reviewer account, the wording of the description), or at least {{ count }} different kinds of structural signal did (a large change within two hours, a burst of commits, many new files). {% endblocktranslate %} {% if rules.include_suspected %} {% translate "In the AI cohort: this installation counts suspected pull requests." %} {% else %} {% translate "Not in the AI cohort: it counts as non-AI." %} {% endif %}
  4. {% translate "No AI" %} — {% blocktranslate trimmed %} the author ticked "None" and no rule matched. {% endblocktranslate %} {% translate "Unknown" %} — {% translate "no rule matched and nothing was ticked." %} {% translate "Neither is in the AI cohort; both count as non-AI." %}

{% blocktranslate trimmed %} Pull requests by bots and by people excluded from metrics are left out of every metric. A signal that does not change the status is still listed on the pull request's page as evidence. {% endblocktranslate %}
