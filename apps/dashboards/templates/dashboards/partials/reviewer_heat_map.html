{% load i18n %} {% comment %} Author x reviewer heat map (plan §4): a server-side HTML table since Chart.js has no matrix type. Rows are authors, columns are reviewers; the corner cell and the column-group header spell that out so the axes are never guessed, and every cell carries a `title` naming both people. Every cell carries the count as visible text as well as its `--heat-0`..`--heat-4` colour (spec §10.5: status is never colour-only) — and so does every flag: a flagged name carries a glyph, a `title` and screen-reader text, a self-review cell a glyph, a same-person cell a dash. `id=None` on either axis is the folded "Other" bucket. The table scrolls sideways inside its own wrapper with the author column pinned, so a wide team never widens the page. {% endcomment %}
