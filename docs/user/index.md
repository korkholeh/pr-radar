# Find the right page

This page is for a lead. It maps what you're trying to do to the page that does it — start here if you're not
sure where to look, or use `getting-started.md` first if you haven't logged in yet.

| I want to… | Page |
|---|---|
| Log in, switch theme or language for the first time | [Getting started](getting-started.md) |
| See the global picture — KPIs, charts, trends | [Read the dashboards](dashboards.md) (Overview) |
| Drill into one project or repository | [Read the dashboards](dashboards.md) |
| See who's using AI tools, and how much | [Read the dashboards](dashboards.md)'s AI-adoption KPIs, or [Tune AI detection](tune-ai-detection.md) if a person's AI status looks wrong |
| Find and close a policy violation | [Handle policy violations](handle-policy-violations.md) |
| Understand exactly why a violation fired | `docs/POLICY.md` (the full rule reference) |
| Look up one person, or compare them to their team | [Look up a person](people.md) |
| Fix a person's name, team, or merge a duplicate | [Map people](map-people.md) |
| Find a specific pull request, or read its full timeline | [Find and inspect a pull request](pull-requests.md) |
| See who's overloaded on reviews, or what's waiting for review | [Read review load and backlog](reviews.md) |
| Understand a PR's churn number, or why it's missing | [Churn: how much of a PR's code survives](churn.md) |
| Get a table or a full report out as a spreadsheet | [Export data and reports](exports.md) |
| Connect a new GitHub repository, or fix a broken connection | [Connect GitHub and sync your repositories](connect-github.md) |
| Something looks empty, stale, or wrong | [Troubleshooting](troubleshooting.md) |

For the rule reference, the metrics reference and the settings reference — as opposed to how to *use* a page —
see `docs/POLICY.md`, `docs/METRICS.md` and `docs/CONFIGURATION.md` instead; those are written for whoever
administers the tool, not for reading a dashboard.
